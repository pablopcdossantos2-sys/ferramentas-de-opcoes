Instalar — EWZ Mapa de Opções em Aberto

Indicador Pine v6: não exige Python e pode ser instalado diretamente no TradingView.

Neste tutorial O que você precisa Instalação Primeiro uso Como validar Limitações

REQUISITOS

O que você precisa

  • Conta no TradingView.
  • Gráfico do EWZ cotado em USD.
  • Arquivo source/EWZ_Mapa_Opcoes.pine.
  • Para uso real, cadeia de opções convertida para o formato do indicador.

PASSOS 1 E 2

Abrir o gráfico e instalar o Pine

  1. Entre no TradingView e pesquise por EWZ.
  2. Abra um gráfico do ETF cotado em dólares e deixe espaço à direita das velas.
  3. Abra o Pine Editor.
  4. Copie todo o conteúdo de EWZ_Mapa_Opcoes.pine, desde //@version=6.
  5. Cole no editor, salve e dê um nome ao indicador.
  6. Clique em Adicionar ao gráfico.

PRIMEIRO USO

Testar antes de usar dados reais

  1. Abra as configurações do indicador.
  2. Ative Demonstração — dados FICTÍCIOS.
  3. Ajuste a escala se necessário.
  4. Confirme que aparecem faixas entre aproximadamente USD 33 e USD 38 e um quadro de dados.

A demonstração serve apenas para confirmar que o indicador está funcionando.

Inserir dados reais

Desative a demonstração e cole uma série por linha no formato:

vencimento;tipo;strike;oi;premio;multiplicador

Exemplo:

2099-12-18;C;35;1000;1.20;100
2099-12-18;P;35;800;0.95;100

Use C para call, P para put, ponto decimal, NA quando o prêmio estiver ausente e informe a data real de referência do OI.

VALIDAÇÃO

Como saber se deu certo

  • O código compila.
  • O indicador reconhece o gráfico do EWZ.
  • As faixas aparecem à direita.
  • O quadro mostra OI e valores.
  • Entradas inválidas geram mensagem em vez de resultados silenciosamente incorretos.

LIMITES

Snapshot manual

O indicador não busca a cadeia automaticamente. Os dados precisam ser atualizados manualmente para cada novo snapshot.
