TUTORIAL DIDÁTICO · INSTALAÇÃO

Instalar e usar o EWZ GEX → WIN

Guia passo a passo para a aplicação desktop/GUI e para o indicador Pine do projeto principal.

Neste tutorial O que você precisa Instalação Primeiro uso Como validar Limitações

ESTADO ATUAL

Aplicação desktop em fase alpha

A aplicação já possui interface gráfica, coleta via Microsoft Edge, processamento local, exportação do bloco EWZGEX1 e integração com dois indicadores Pine: um para plotagem direta no EWZ e outro para projeção no WIN. Ainda estamos validando a coleta em diferentes máquinas e comparando os níveis extraídos com o Barchart antes de chamar a versão de estável.

Importante

O tutorial abaixo já permite testar a versão de desenvolvimento. Quando houver uma Release estável, esta página será atualizada para apontar para o instalador/ZIP definitivo.

REQUISITOS

O que você precisa

  • Windows 10 ou 11.
  • Microsoft Edge instalado e atualizado.
  • Se você usa Cold Turkey, mantenha a extensão instalada no seu perfil normal do Edge. A aplicação agora detecta e replica as extensões para o perfil de automação.
  • Conta no TradingView.
  • Acesso a um gráfico do WIN ou do ativo em que deseja visualizar as projeções.

A versão portátil não exige que o usuário instale Python para executar o aplicativo compilado.

INSTALAÇÃO · APLICAÇÃO DESKTOP

Opção A — usar o ZIP gerado pelo GitHub Actions

1

Abra o repositório no GitHub

Entre na aba Actions e abra o workflow Build EWZ GEX WIN Desktop.

2

Escolha a execução mais recente concluída com sucesso

Na parte inferior da execução, procure o artifact EWZ-GEX-WIN-Desktop-Windows.

3

Baixe e extraia o ZIP

Extraia a pasta para um local de sua preferência, por exemplo Documentos\EWZ-GEX-WIN. Não é necessário instalar o programa no Windows.

4

Execute o aplicativo

Abra EWZ-GEX-WIN-Desktop.exe mantendo o executável dentro da pasta extraída, pois a versão alpha usa arquivos internos ao lado dele. O Microsoft Edge poderá ser aberto pela aplicação para carregar a página do Barchart.

Windows SmartScreen

A build alpha ainda não é assinada digitalmente. Por isso, o Windows pode mostrar um aviso de aplicativo desconhecido. Esse ponto deverá ser revisado antes da distribuição estável.

Opção B — executar a partir do código-fonte

Essa opção é destinada a desenvolvimento. Requer Python 3.11 ou superior.

cd ferramentas\ewz-gex-win\desktop
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py

PRIMEIRO USO

Coletar os dados e gerar o bloco

1

Confirme o perfil do Edge

Na seção Edge e extensões, mantenha marcada a opção Usar minhas extensões do Edge. A aplicação lista seus perfis e indica quando o Cold Turkey foi localizado. Se necessário, selecione outro perfil e clique em Detectar novamente.

2

Clique em “Atualizar Barchart”

A aplicação copia as extensões do perfil escolhido para um perfil isolado próprio e abre o Edge com essas extensões ativas. O Edge fica visível quando esse modo está habilitado.

3

Conclua uma eventual verificação do site

Se o Barchart pedir confirmação de navegador/anti-robô, conclua-a na janela do Edge. A aplicação mantém um perfil próprio para reaproveitar a sessão em execuções futuras.

4

Revise os níveis

A tabela informa o valor, a origem e a confiança. Call Wall, Put Wall e Gamma Flip podem ser marcados como extraídos da página; níveis auxiliares podem aparecer como estimativas locais de baixa confiança.

5

Copie o bloco

Clique em Copiar bloco. O resultado começa com EWZGEX1| e reúne todos os níveis em uma única linha.

Instalar o indicador Pine

  1. Abra o TradingView e um gráfico do WIN.
  2. Abra o Pine Editor.
  3. Abra EWZ_GEX_WIN_Pro.pine no repositório e copie o conteúdo completo.
  4. Cole no Pine Editor, salve e clique em Adicionar ao gráfico.
  5. Abra Configurações → Inputs.
  6. Em Origem dos níveis, escolha Bloco do aplicativo.
  7. Cole a linha gerada pela aplicação no campo Bloco EWZGEX1.

O modo Manual individual continua disponível como fallback.

Não cole o bloco dentro do código Pine

O texto EWZGEX1|... deve ser colado somente na janela de Configurações do indicador → Aplicação desktop → Bloco EWZGEX1. Colá-lo em uma linha como tooltip = EWZGEX1|... gera erro de sintaxe, porque tooltip aceita uma string entre aspas, não o bloco de dados sem aspas.

INDICADOR DIRETO DO EWZ

Plotar no próprio EWZ os níveis de gamma do Barchart

A aplicação agora atende a dois objetivos com a mesma coleta. O indicador EWZ_GEX_EWZ_Pro.pine recebe o bloco EWZGEX1 e desenha os níveis diretamente no gráfico de preço do EWZ, sem qualquer projeção para o WIN.

  1. Na aplicação, clique em Atualizar Barchart.
  2. Mantenha marcada a opção Indicador EWZ: copiar somente níveis realmente extraídos do Barchart para evitar que proxies locais sejam apresentados como níveis publicados pelo site.
  3. Clique em Copiar para indicador EWZ.
  4. No TradingView, abra um gráfico AMEX:EWZ, instale EWZ_GEX_EWZ_Pro.pine pelo Pine Editor e adicione-o ao gráfico.
  5. Abra Configurações → 1. Aplicação desktop → Bloco EWZGEX1 e cole o bloco.

As linhas exibidas correspondem diretamente aos preços do EWZ: Call Wall, Put Wall, Gamma Flip e demais níveis que estiverem presentes no bloco. O painel também mostra a distância percentual do preço atual do EWZ até cada nível.

Diferença entre os dois indicadores

No gráfico do EWZ, o valor do nível é usado diretamente. No gráfico do WIN, o nível passa pela projeção percentual EWZ → WIN. Portanto, não há cálculo de conversão no indicador direto do EWZ.

MÉTODO DA PALESTRA

Como a projeção EWZ → WIN é calculada

A aplicação agora separa EWZ atual / pré-mercado de Fechamento EWZ D-1. O preço atual ajuda a contextualizar os strikes; o fechamento anterior é a referência usada na régua percentual da palestra.

variação = nível EWZ / fechamento EWZ D-1 - 1
nível WIN = fechamento WIN no mesmo instante × (1 + variação)

O modo principal do Pine é 1:1 (método original). O modo com beta ficou explicitamente marcado como experimental.

Auditoria

O bloco EWZGEX1 agora também carrega ewzref. No painel do Pine, a referência do aplicativo pode ser comparada com a referência sincronizada obtida pelo TradingView. Se houver diferença relevante, não trate a projeção como validada até descobrir a causa.

TESTE DA VERSÃO 0.2 ALPHA

O que precisamos conferir no seu computador

Depois de instalar a build mais recente, faça uma única coleta antes do pregão e registre os resultados. O objetivo desta etapa é validar a seleção automática dos níveis; a fórmula de projeção percentual já está definida.

  1. Abra a aplicação e confirme que o perfil do Edge mostra Cold Turkey ✓.
  2. Clique em Atualizar Barchart e aguarde a coleta.
  3. Anote os valores exibidos em EWZ atual / pré-mercado e Fechamento EWZ D-1 (referência).
  4. Clique em Perfil GEX por strike e confira se aparecem strikes, Call GEX, Put GEX, Net GEX, Call OI e Put OI.
  5. Na página do Barchart, compare visualmente Call Wall, Put Wall, Gamma Flip e os principais picos com os níveis escolhidos pela aplicação.
  6. Clique em Copiar bloco e cole o texto somente em Configurações do indicador → Bloco EWZGEX1.
  7. No painel do Pine, confira a referência do aplicativo (App ref.) contra a referência automática do TradingView. Uma diferença relevante deve ser registrada.
Se houver divergência

Salve o snapshot usando Salvar JSON e, se possível, faça uma captura da página do Barchart mostrando o mapa de gamma do mesmo momento. Esses dois itens permitem comparar exatamente o que o site exibiu com o que a aplicação classificou.

VISUALIZAÇÃO NO GRÁFICO

Linhas dos níveis calculados no WIN

O indicador foi configurado com overlay = true e desenha diretamente no gráfico de preço do WIN as linhas horizontais dos níveis projetados. Em Configurações → 5. Visual, mantenha marcada a opção Mostrar linhas dos níveis projetados no gráfico de preço.

Cada rótulo mostra o nome do nível, o preço projetado do WIN, o strike correspondente do EWZ e a variação percentual usada na projeção. Assim, por exemplo, uma linha pode aparecer como Call Wall 1 · WIN 179105 · EWZ 36 · Δ 0,68%.

É possível ativar ou desativar individualmente Call Walls, Put Walls, Gamma Flip e os demais níveis na seção 4. Níveis GEX do EWZ.

VALIDAÇÃO

Como saber se funcionou

  • A aplicação exibe o spot do EWZ e uma lista de vencimentos/strikes processados.
  • O botão Copiar bloco gera uma linha iniciada por EWZGEX1|.
  • O Pine compila sem erro.
  • Ao colar o bloco, o painel do indicador passa a exibir os níveis EWZ e suas projeções para o WIN.
  • Os preços projetados são coerentes com a referência EWZ/WIN usada pelo indicador.

LIMITAÇÕES

O que ainda está sendo validado

O Barchart informa que seus níveis de Gamma Exposure usam gamma, Open Interest e um movimento de 1% do ativo; a aplicação usa uma aproximação local compatível com essa ideia para construir o perfil por strike. Isso não é apresentado como reprodução exata do cálculo proprietário do site.

Cold Turkey / outras extensões

O modo de compatibilidade copia as extensões e o estado necessário para um perfil separado da aplicação. Isso é preferível a automatizar diretamente o perfil normal do Edge, que pode estar aberto e bloqueado por outro processo. Se uma extensão depender de uma política corporativa ou de dados não copiáveis, ela ainda poderá exigir validação adicional.

O Gamma Flip não é inventado quando não pode ser extraído de forma confiável. Os níveis auxiliares específicos da metodologia original — como “Call/Put teto”, “Gamma resistência” e “Gamma suporte” — são claramente identificados quando forem apenas proxies locais.
