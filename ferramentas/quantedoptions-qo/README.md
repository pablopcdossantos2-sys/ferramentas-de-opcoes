# quantedOptions Levels [qO]

Indicador Pine v6 recebido para análise.

## Recursos principais

- Call Wall / Put Wall;
- Gamma Flip;
- Gamma C/P e DEX C/P;
- Top 5 strikes;
- perfil/ladder de net GEX por strike;
- zona entre as walls;
- conversão automática entre ETFs/índices e futuros correlatos.

O Pine recebe um snapshot externo em texto; não coleta a cadeia diretamente.
