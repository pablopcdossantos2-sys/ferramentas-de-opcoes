Instalar — quantedOptions Levels [qO]

Instalação do componente Pine e uso do snapshot externo no TradingView.

Neste tutorial O que você precisa Instalação Primeiro uso Como validar Limitações

REQUISITOS

O que você precisa

  • Conta no TradingView.
  • Arquivo source/quantedOptions_Levels_qO.pine.
  • Um snapshot compatível para uso real.

PASSO 1

Instalar o Pine

  1. Abra um gráfico no TradingView.
  2. Abra o Pine Editor.
  3. Copie o código completo do arquivo preservado no repositório.
  4. Apague o conteúdo atual do editor e cole o código.
  5. Salve, dê um nome ao indicador e clique em Adicionar ao gráfico.

PASSOS 2 E 3

Entender e inserir o snapshot

O indicador não coleta a cadeia e não calcula sozinho Call Wall, Put Wall, Gamma Flip, GEX ou DEX. Ele espera um snapshot textual produzido externamente, com prefixo/versionamento como qo1|.

  1. Abra Configurações → Inputs.
  2. Localize o campo destinado ao snapshot.
  3. Cole o texto completo produzido pelo gerador compatível.
  4. Confirme.
  5. Verifique ticker, data/hora e níveis no header.

Outro ativo/proxy

Use apenas pares reconhecidos pela lógica de conversão do script e confira o estado de conversão mostrado pelo indicador.

VALIDAÇÃO

Como saber se deu certo

  • O Pine compila sem erro.
  • O snapshot é reconhecido.
  • Call Wall, Put Wall e Gamma Flip aparecem.
  • Top strikes e ladder são desenhados quando presentes.
  • O header não indica erro de parsing.

LIMITAÇÃO

Gerador externo não incluído

O repositório preserva o indicador Pine, não o gerador original de snapshots. A aquisição dos dados depende do ecossistema externo correspondente.
