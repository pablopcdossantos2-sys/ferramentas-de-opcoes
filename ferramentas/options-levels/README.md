# Options Levels

Indicador Pine v5 simples para 13 níveis pré-calculados.

Ordem esperada: Call Wall, Put Wall, Gamma Flip, Dark Gamma, Whale 1–5, Upper σ1/σ2 e Lower σ1/σ2.

Seu principal mérito é a simplicidade de uso e de visualização. A aquisição e o cálculo dos níveis ocorrem fora do indicador.
