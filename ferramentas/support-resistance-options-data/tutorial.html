TUTORIAL DIDÁTICO · INSTALAÇÃO

Instalar — Support and Resistance levels from Options Data

Instalação do Pine, entrada da string externa e configuração dos alertas.

Neste tutorial O que você precisa Instalação Primeiro uso Como validar Limitações

REQUISITOS

O que você precisa

  • Conta no TradingView.
  • Arquivo source/Support_and_Resistance_levels_from_Options_Data.pine.
  • Uma string compatível com os campos esperados.

PASSO 1

Instalar o código

  1. Abra um gráfico no TradingView.
  2. Abra o Pine Editor.
  3. Copie todo o arquivo preservado no repositório.
  4. Cole no editor, salve, dê um nome e clique em Adicionar ao gráfico.

PASSOS 2 A 4

Inserir os dados e configurar alertas

A string por ticker reúne S1/R1, Implied Move, Put/Call Wall, Gamma Flip, IV, Put/Call Ratio, tendência, atividade, Walls de curto prazo e anteriores, Vanna ± e stop sugerido.

  1. Abra Configurações → Inputs.
  2. Cole a string completa preservando separadores e ordem.
  3. Confirme e verifique se os níveis correspondem ao ticker do gráfico.
  4. Para alertas, abra Criar alerta, selecione o indicador, escolha a condição e configure frequência/notificação.

VALIDAÇÃO

Como saber se deu certo

  • O Pine compila.
  • Os níveis principais aparecem.
  • O painel mostra métricas coerentes com o ticker.
  • As condições de alerta ficam disponíveis.

LIMITAÇÃO

Gerador externo não incluído

A instalação do Pine não instala nem reproduz o gerador externo dos 17 campos. Sem uma fonte compatível, o indicador não preenche sozinho as métricas.
