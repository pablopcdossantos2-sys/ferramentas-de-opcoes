## Uso no portfólio

Essas imagens são referências visuais das páginas públicas originais e ajudam o leitor a compreender como cada indicador se apresenta no gráfico. Elas não são tratadas como prova de desempenho, recomendação de negociação ou autoria deste repositório.

Quando uma nova ferramenta for adicionada junto com uma imagem relevante, a imagem deve ser preservada no acervo sempre que houver uma fonte que possa ser arquivada de forma adequada, acompanhada da respectiva atribuição/origem.
